Nuevos Aires

Identidad visual y sistema de marca para un proyecto que reinventa prendas con identidad propia.

El Desafío

Nuevos Aires nació con la premisa de que la moda no tiene por qué ser estática ni descartable. El reto consistió en crear una identidad que unificara dos universos: el upcycling de prendas existentes y la creación de piezas nuevas de autor. Necesitábamos un sistema visual que transmitiera esa "reinvención" sin perder el orden, logrando que cada prenda —nueva o recuperada— se sintiera parte de un mismo mensaje coherente y auténtico."

La Solución

A través de una paleta orgánica y un sistema visual que permite que la prenda sea la protagonista, logramos el marco de profesionalismo necesario para un emprendimiento de autor.

El equilibrio tipográfico: Combinamos una fuente estructural con una intervención manual y fluida, simbolizando cómo a partir de lo rígido es posible crear una nueva versión llena de vida y movimiento.
